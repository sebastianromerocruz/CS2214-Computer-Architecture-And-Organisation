Four Questions Fall Out of This

Answering all four is essentially the whole of sequential logic.

  1. How do you set the running total's initial value? A Reset signal.
  2. How does the circuit know when a new input has arrived? A Clock signal.
  3. How does it physically hold the running total between inputs? A register.
  4. How do you write any of this down in Verilog? The always @(posedge clk) construct.
